# 俄罗斯方块项目验收清单

## 核心玩法

- [x] 棋盘为 12 列 × 16 行。
- [x] 方块可以左右移动、顺时针旋转、软降和硬降。
- [x] 支持碰撞检测、锁定、消行、计分、等级加速和游戏结束。
- [x] 支持 P 暂停/继续和 Esc 返回主菜单。
- [x] 分数和消行数按十进制显示。

## 扩展功能

- [x] 双人本地对战，两块棋盘和两套按键互相独立。
- [x] 消除两行或以上时向对手发送垃圾行。
- [x] AI 启发式落点规划。
- [x] AI 观战模式屏蔽人工操作。
- [x] AI 观战模式 F9 切换普通速度和 2 倍速。
- [x] 回放记录随机种子、命令、Tick 和 AI 回合。
- [x] 回放支持暂停和 0.25× 到 4× 调速。
- [x] 主菜单 5 或 F6 打开录像列表，支持选择、翻页和重新扫描，兼容旧 JSON 录像。
- [x] 通过 `IScoringRule`、`IGamePieceSource` 和 `IScoreHistoryStore` 扩展核心行为。

## 持久化与异常

- [x] 最高分保存到 `%LOCALAPPDATA%\\Tetris\\highscore.xml`。
- [x] 历史成绩保存到 `%LOCALAPPDATA%\\Tetris\\scores.db`。
- [x] 主菜单按 4 查询前 10 名排行榜。
- [x] XML 缺失、损坏或不可写时回退/提示并继续运行（自动化 + 手工验证）。
- [x] SQLite 损坏、被占用或目录无权限时返回错误并继续运行（损坏文件已自动化验证；占用/只读目录需在演示机手工验证）。
- [x] 损坏的回放文件会被跳过。
- [x] 窗口尺寸不足时显示调整提示，不执行越界绘制。
