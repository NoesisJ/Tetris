# SQLite 成绩库查看说明

程序使用本地 SQLite 保存历史成绩，不连接 MySQL 服务。

数据库文件：

```text
%LOCALAPPDATA%\\Tetris\\scores.db
```

运行游戏并完成一局，或在主菜单按 `4` 打开排行榜后，程序会创建目录、数据库文件和 `ScoreHistory` 表。

## 使用 DBeaver

1. 新建数据库连接，选择 **SQLite**。
2. 在数据库文件中选择 `scores.db`，不要选择 `C:\\Windows\\Temp` 下的临时文件。
3. 路径使用 DBeaver 的“浏览”按钮选择，不要手动添加引号。
4. 连接成功后展开 `Tables -> ScoreHistory`。
5. 刷新连接后执行下面的查询：

```sql
SELECT Id, PlayerName, Score, TotalLines, GameMode, PlayedAtUtc
FROM ScoreHistory
ORDER BY Score DESC, PlayedAtUtc ASC, Id ASC
LIMIT 10;
```

## 字段含义

| 字段 | 含义 |
| --- | --- |
| `Id` | 成绩记录编号 |
| `PlayerName` | 玩家名称或 AI |
| `Score` | 本局分数 |
| `TotalLines` | 本局消除行数 |
| `GameMode` | 单人游戏、双人对战或 AI 观战 |
| `PlayedAtUtc` | 以 UTC 保存的结束时间 |

如果出现 `SQLITE_CANTOPEN`，优先检查选择的文件是否真实存在、文件夹是否可读写，以及是否误用了 MySQL 的 `localhost:3306` 连接。SQLite 不需要主机、端口、用户名或密码。
