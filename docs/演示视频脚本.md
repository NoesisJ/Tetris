# 俄罗斯方块演示视频脚本

建议时长：2 到 3 分钟。录制时使用 Windows Terminal 或 VS Code 集成终端，确保窗口足够宽。

## 0:00-0:20 启动与环境

1. 展示仓库根目录和 `dotnet --version`。
2. 运行 `artifacts/publish/win-x64/Tetris.Console.exe`。
3. 简单说明棋盘为 12 × 16，当前发布版为 Windows x64 self-contained。

## 0:20-0:55 单人核心玩法

1. 按 `1` 开始单人游戏。
2. 使用 A/D 移动、W 旋转、S 软降、空格硬降。
3. 展示分数、等级、已消行数和下一个方块。
4. 按 `P` 暂停，再按 `P` 继续；按 Esc 返回主菜单。

## 0:55-1:25 双人对战

1. 按 `2` 进入双人模式，展示两块独立棋盘。
2. 左侧使用 WASD 和空格，右侧使用方向键和 Enter。
3. 通过预先准备的局面或连续操作展示消除多行后产生垃圾行。
4. 说明两块棋盘由两个独立的游戏状态管理。

## 1:25-1:55 AI 观战

1. 返回菜单后按 `3` 进入 AI 观战。
2. 展示 AI 自动移动、旋转和自然下落。
3. 按 A、D、W、S、空格或方向键，说明这些人工操作不会改变 AI 棋盘。
4. 按 `F9` 切换普通速度和 2 倍速，说明只改变观战速度。

## 1:55-2:20 回放与排行榜

1. 使用 `F5` 保存一局回放，使用 `F6` 播放最近回放。
2. 使用 `F8` 暂停，使用 `+` 或 `-` 调整回放速度。
3. 返回主菜单按 `4` 查看历史排行榜。

## 2:20-2:55 异常场景（建议录 XML 损坏）

这一段不需要制造系统故障，使用程序自己的本地存档即可。先按 `Q` 退出游戏，在 PowerShell 中执行下面的命令备份并损坏 XML：

```powershell
$save = Join-Path $env:LOCALAPPDATA 'Tetris'
Copy-Item (Join-Path $save 'highscore.xml') (Join-Path $save 'highscore.xml.bak') -Force
Set-Content (Join-Path $save 'highscore.xml') '<HighScore score="broken">' -Encoding UTF8
```

重新启动 `Tetris.Console.exe`。程序应正常进入主菜单，最高分回到 `0`，不会闪退；随后按 `1` 仍可开始新局。这说明 XML 缺失或格式损坏时会回退到默认值，游戏逻辑不受影响。演示结束后恢复文件：

```powershell
Move-Item (Join-Path $save 'highscore.xml.bak') (Join-Path $save 'highscore.xml') -Force
```

有时间时再录回放文件异常：在 `%LOCALAPPDATA%\\Tetris\\replays` 中把最新 JSON 复制一份并改成 `{ broken json`，启动游戏后按 `F6`，程序提示没有可读取的回放并继续运行；删除测试文件即可恢复。

最后展示自动化验证结果：

```powershell
dotnet test Tetris.slnx -c Release --no-restore
```
