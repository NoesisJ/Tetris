# 录像选择更新与验证记录

## 问题与修改

原来的 F6 按文件最后写入时间加载最近一份有效录像，不按得分筛选，但缺少浏览其他录像的入口。

现在主菜单 5 或 F6 打开录像列表，显示保存时间、模式和录制时长。上下键或 W/S 选择，Enter/空格播放，PageUp/PageDown 翻页，每页 8 条；F6 刷新，Esc 返回菜单。旧版 JSON 文件不需要迁移。

列表会跳过损坏或无法读取的文件并提示。播放前再次读取并校验文件，因此列表打开后文件被删除、占用或改坏也不会导致崩溃。回放中只接收播放控制，人工操作不能改变棋盘；播放结束保持最后一帧，避免重新开始实时下落。

录像仍由玩家按 F5 保存，包含保存前的操作，不要求取得最高分。进入列表会离开当前游戏，因此需要先保存要保留的录像。

## 自动化测试

```powershell
dotnet test Tetris.slnx -c Release --no-restore
```

100 项通过、0 项失败、0 项跳过，其中新增录像相关测试 24 项，覆盖存储、输入映射、控制器、列表格式化和页面切换渲染。

## 发布和交互验证

```powershell
dotnet publish src/Tetris.Console/Tetris.Console.csproj -c Release -r win-x64 --self-contained true -o artifacts/publish/win-x64
```

第一次发布因旧游戏运行导致 DLL 被锁定而失败；退出旧游戏后重新发布成功，最终发布无警告和错误。发布目录中的 `Tetris.Console.dll` 与本次构建产物 SHA256 一致。

使用发布版在交互终端中启动，按 5 成功列出本机原有的单人和双人录像；按 S 选中较旧的录像，再按 W 切回新录像，按 Enter 开始播放，随后按 Q 正常退出。该检查没有创建测试录像或修改用户录像。

当前使用入口：`artifacts/publish/win-x64/Tetris.Console.exe`。`win-x64-fixed` 是旧发布目录，本次未更新。
