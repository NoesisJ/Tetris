## 发布验证

执行命令：

```powershell
dotnet publish src/Tetris.Console/Tetris.Console.csproj `
  -c Release -r win-x64 --self-contained true `
  -o artifacts/publish/win-x64
```

发布目录为 `artifacts/publish/win-x64`，入口文件为 `Tetris.Console.exe`。该目录包含 .NET 运行时和 SQLite 原生库，适合在 Windows x64 机器上直接运行。

## 手工验收项目

- 单人模式：移动、旋转、软降、硬降、暂停和返回菜单。
- 双人模式：WASD 与方向键分别控制两个棋盘，垃圾行只发送给对手。
- AI 观战：人工操作不生效，F9 在普通速度和 2 倍速间切换。
- 回放：F5 保存，F6 播放，F8 暂停，`+/-` 调整速度。
- 数据库：主菜单按 4 查询排行榜，DBeaver 可打开 `%LOCALAPPDATA%\\Tetris\\scores.db`。
- 异常：删除或损坏 XML、回放或 SQLite 文件后重新启动，程序显示提示并继续运行。
