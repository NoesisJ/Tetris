## 需要在演示机手工确认

以下场景依赖 Windows 终端和文件系统状态，单元测试不适合强行模拟：

- 游戏运行时快速连续按键、同时按下两组方向键：输入循环逐个消费按键，未知键映射为 `None`，不应抛异常。
- 游戏运行时缩放窗口：渲染器检测最小尺寸并显示提示，恢复窗口后继续绘制。
- 文件被其他程序占用或目录只读：高分保存失败时显示“高分存档不可写”，本局仍可继续；SQLite 查询失败时显示数据库错误，主循环不退出。

视频中建议使用 XML 损坏场景，因为它可重复、风险低，而且能清楚展示“异常文件存在但程序仍能启动”。不要在录制过程中直接删除正在使用的 SQLite 文件，Windows 可能因为文件锁定而产生额外提示。
